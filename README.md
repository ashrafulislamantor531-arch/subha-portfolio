# SUBHA — Fine Art & Watercolorist Portfolio

A luxury, glassmorphic portfolio web application showcasing original watercolor artworks, fine art collections, and bespoke commission works by **SUBHA**.

---

## ✨ Features

- **Glassmorphism Aesthetic**: Multi-layered frosted glass surfaces with `backdrop-filter: blur(20px)`, specular reflections, and ambient glowing orbs.
- **Interactive 3D Perspective Tilt**: Gyroscope-inspired dynamic card tilt that responds to mouse hover and movement.
- **Original Artwork Gallery**: High-resolution watercolor paintings with curated metadata (medium, Arches 300gsm paper, dimensions, year).
- **Interactive Lightbox Modal**: Seamless full-screen inspection mode with keyboard navigation (`Esc`, `ArrowLeft`, `ArrowRight`).
- **Category Filtering**: Smooth animated transitions between Landscapes, Flora & Fauna, Cottages, and Abstract Studies.
- **Bespoke Commission Form**: Integrated inquiry form with micro-interactions and glass toast notifications.
- **Fully Responsive**: Flawless experience across mobile, tablet, laptop, and ultra-wide displays.
